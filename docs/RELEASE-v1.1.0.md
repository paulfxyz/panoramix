# Panoramix v1.1.0 — the druid, redrawn

A complete redesign of askpanoramix.com.

**Art direction.** Monochrome at rest in the spirit of calliope.agency: black and white, Space Grotesk set large and bold, pill buttons, generous spacing, dark theme. Red appears only as transient interaction feedback. Panoramix himself is now an original Gaulish druid in copperplate-engraving style, with four companion engravings.

**Ask works.** The brief field is a single large input; Enter submits and results scroll into view with "why" chips.

**Simpler data, richer comparison.** Large cards with a six-dimension coverage strip replace the table. A per-tool field-notes drawer, a comparison dock, and Radar / Bars / Matrix / Facts views for up to four tools.

**Motion.** Button lift, halo and light sweep; animated add/check toggle; focus underline; scroll reveals; drawer and compare transitions; radar and bar animations. Reduced-motion aware.

**Unchanged.** Catalogue schema, community report standard, merge tooling, static hosting, MIT licence, SiteGround deployment workflow.

Hosting package: `packages/panoramix-siteground-v1.1.0.zip` (SHA-256 in `packages/SHA256SUMS`).
