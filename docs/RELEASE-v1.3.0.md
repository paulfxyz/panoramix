## Record
34 new tools from official sources bring the record to **82 tools in 10 families**: Microsoft 365 Copilot, Relevance AI, Helicone, Kong AI Gateway, Eden AI, SambaNova, Hyperbolic, Lambda Inference, Featherless, Stability AI, Black Forest Labs, Segmind, CoreWeave, Vast.ai, Hugging Face Inference Endpoints, IBM watsonx.ai, Databricks Mosaic AI, Google Gemini API, xAI, DeepSeek, Cohere, Moonshot Kimi, Windsurf, Bolt.new, v0, Replit Agent, GitHub Copilot coding agent, Pipedream, Activepieces, Dify, Luma Dream Machine, Kling AI, Suno, Ideogram.

## Cases
- **500 ready-made cases**: 45 hand-written plus cases generated deterministically from the record (alternatives to every tool, head-to-heads inside each family, family × capability filters, capability combinations, family views).
- Shown **one per line** with a group badge and the view each opens. A **filter field** narrows by tool, capability or word.
- **Ten rotate every two minutes**; Next ten and Reshuffle; hover pauses.
- **Prepared setup**: pick a head-to-head and the selection is already made. Remove, add or swap tools (suggestions from the same family first), choose the opening view (capability table by default), see a preview radar, then run.
- Lens cases open preset and fully adjustable.
