# Panoramix v1.0.0

Find your magic mix. The first public MIT release of Panoramix's static AI-tool comparison workbench.

## Inside

- 48 tools across 10 primary families, including AI agent workspaces, model APIs and gateways, inference, media, coding, automation and creative studios.
- Original apothecary identity, potion-leaf logo, alchemist illustration, responsive controls and reduced-motion support.
- Search and capability filters, local brief matching, ten recipes, four-tool comparisons, source-linked field notes and landscape graphics.
- User-input cost scenarios for tokens, media outputs, GPU hours and seats. No live-price or universal-benchmark claim.
- A standalone JSON catalogue, a documented community research format, field-level evidence and a conflict-safe reviewed merge process.
- Validation, type checking, ten regression tests, static packaging and an optional manual secret-backed FTPS workflow.

## Host it

Download the [ready-to-host static ZIP](https://github.com/paulfxyz/panoramix/raw/refs/heads/main/packages/panoramix-siteground-v1.0.0.zip), verify it with the [SHA-256 checksum](https://github.com/paulfxyz/panoramix/blob/main/packages/SHA256SUMS), extract it and upload its contents to your configured web root. No backend, database, API key or Node runtime is needed on the host. Domain, DNS and HTTPS configuration are separate operator steps.

The compiled ZIP is repository-hosted because the connected GitHub integration could not upload binary release assets. The auto-generated GitHub source archives are not the compiled hosting package.

The public home is intended to be https://askpanoramix.com. This release does not itself prove that the domain has been deployed.

Read the README for hosting, `CONTRIBUTING.md` for community reports and `docs/DEPLOYMENT.md` for the optional path-verified FTPS action.

## Limits

The initial research snapshot is 22 October 2026. Product scope and prices change. Classification and use cases are editorial; missing information is not evidence of non-support. The matcher is local and rule-based, not a hosted AI service. No automatic report acceptance, paid polling, account system or automatic deployment is installed.
