# Main flows (v1.2)

## Landing and navigation
- Checks, Browse, Recipes, The record, The druid scroll to sections; theme toggle persists; header CTA "Open the record".

## Cases
- Filter field narrows the 500 cases (ranked: whole word, prefix, substring); clear (×) resets.
- Group tabs filter; counts match; "All 500" lists everything, 30 at a time.
- With no filter: ten cases shown, rotating every 120 s; bar depletes; hover pauses (bar turns red); Next ten / Reshuffle.
- A lens-backed case opens the lens panel preset with the case's configuration; everything stays adjustable.
- A compare-backed case opens the prepared setup: selected tools, add field + suggestions (same family first), view selector (Table default), preview radar, "Compare N now" (enabled at ≥2).
- Close (×) returns to the cases.

## Lenses
- Radar gallery: family tabs; one radar per tool; + adds to dock; radar click opens drawer.
- Capability matrix: family tabs; sticky first column and header; filled/empty dots; Σ counts.
- Constellation: hover shows card with radar; click opens drawer; family filter dims others.
- Rivers: hover isolates ribbons; click a family → Browse filtered.
- Alternatives: reference chips; neighbours with Shares / Also documents / Not established; "Compare with top 3".
- I need…: family + capability chips; count sentence; grouped results; empty state → stack builder.
- Stack builder: one chip per layer; sidebar radar and coverage; "Compare this stack" enabled at ≥2.

## Compare
- Verdict lines appear for ≥2 tools; Matrix groups differences first; Radar/Bars/Facts unchanged; Copy text; Escape closes.

## Record
- Seal shows Intact when served catalog.json hash equals build hash; commit link; SHA shown; download link.

## Responsive
- 1440 and 375: no horizontal overflow; constellation hides labels on mobile; sticky asides unstick under 1100px.
